# Calvin Operating Metrics Archive

**Status:** historical archive only  
**Retired from live operation:** 2026-09-20  
**Retired by:** Paul OS cutover

This directory preserves the former MOOSE/Physics operating-process metrics exactly as historical evidence.

Archived content:

```text
docs_metrics/
  -> former docs/metrics/** tree

metrics_closure.md
  -> former docs/protocols/metrics_closure.md
```

These records describe the Calvin-era attempt to measure rule application, interaction efficiency, incident learning, and closure cost.

They are **not** live Paul authority and must not be loaded by `moose-test-init`, used as routing input, or required for issue/work closure.

Retired live metrics include:

```text
WCC / T-WCC / RVR / EVR / DBR / RWR / CLR / FBR
weighted rule-load thresholds
working-set activation scores
incident/prevention percentages used to evaluate operating-rule quality
```

This archive does not retire scientific, runtime, numerical, convergence, accuracy, performance, or scalability metrics used by Physics validation.

Historical documents elsewhere may still cite the old paths or metric IDs. Interpret those references as historical Calvin evidence.
