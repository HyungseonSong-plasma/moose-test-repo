# Development Logs

Use this directory for chronological sol-adapter-moose development notes that are broader than a single failure incident.

Recommended filename:

```text
YYYY-MM-DD_<topic>.md
```

Recommended contents:

```text
Goal
Known-good baseline
Changes attempted
Observed output
Decision
Next gate
Relevant test paths
Executable/build identifier
```

Failure investigations with hypothesis/elimination history belong in `docs/incidents/`. Reusable, closed lessons belong in `docs/knowledge/`.
