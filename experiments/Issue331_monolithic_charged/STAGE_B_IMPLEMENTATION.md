# Stage-B implementation splice contract

This document turns the Stage-A ownership census into an executable construction recipe. It is intentionally independent of Issue #310 mutations.

## Source-of-truth inputs

- accepted charged-heavy semantics: Issue #306 Sequence08 at `1b28a1bccbec4ccad5e597500142a7e7e06ef4a3`;
- electron/energy semantics: Sequence08 `fast_sub.i` generated by `wall08_control.py`;
- ordinary Poisson structure: current Poisson child, but **not** its frozen AuxVariable charge ownership;
- historical Issue29 monolithic input: structural evidence only.

## Single-problem nonlinear unknown vector

`X = [log_e, n_epsilon, w_O2p, w_Om, w_Op, potential_plasma]`.

No `potential_from_poisson`, `log_e_frozen`, `w_O2p_frozen`, `w_Om_frozen`, or `w_Op_frozen` may exist in the prototype.

## Frozen neutral state for the first discriminator

The first Stage-B run deliberately does not solve gas flow or neutral chemistry. Neutral quantities needed by the charged equations are read-only fields/constants taken from the same accepted baseline state: gas velocity, pressure/density, gas temperature, O2/O2*/O/O* composition, and neutral-dependent transport coefficients. This freeze is a discriminator device, not the Stage-E production architecture.

## Electron splice

Copy the accepted Sequence08 electron continuity and energy residuals without changing their physical coefficients, timestep, wall closure, or stopping tolerances. Replace every electrostatic owner `potential_from_poisson` with the nonlinear variable `potential_plasma`.

The electron number density passed to charge density must remain an AD expression of the nonlinear log variable:

`n_e = N_A * exp(log_e)`.

Do not materialize this through an AuxVariable. The Poisson row must retain `dR_phi/dlog_e`.

## Charged-heavy splice

Promote `w_O2p`, `w_Om`, and `w_Op` into the same nonlinear variable block. For each ion retain all accepted Sequence08 terms:

1. conservative `rho*w` time derivative;
2. neutral-carrier advection;
3. mixture-averaged diffusion;
4. signed electrostatic migration using `potential_plasma`;
5. mass-frame electromigration correction;
6. accepted thermal wall loss / boundary exclusions;
7. accepted source term state (chemistry remains OFF for this first discriminator, matching Sequence08).

Pure drift+diffusion is not an admissible substitute because it would silently change the accepted ion physics.

## Ordinary Poisson splice

Keep the physical Poisson equation unchanged. Construct `QPXPlasmaChargeDensityMaterial` (or the current accepted equivalent) directly from nonlinear `w_O2p,w_Om,w_Op` and the AD electron density expression from `log_e`. Feed its `poisson_charge_source` directly to the Poisson `FVCoupledForce`/source residual. Do not introduce a Boltzmann closure or screening/reaction term.

## Stage-C genuine-monolithic gates

Before any performance claim, prove both Jacobian directions:

- charged rows -> potential: electron drift, electron energy/Joule, O2+/O-/O+ migration depend on `potential_plasma`;
- Poisson row -> charged state: charge source preserves AD dependence on `log_e,w_O2p,w_Om,w_Op`.

A run that converges while one of these dependencies is stripped is classified `UNRESOLVED`, not `SUPPORTED`.

## Execution order

1. generate `monolithic_charged.i` from the accepted source owners;
2. run `prototype_contract.py monolithic_charged.i`;
3. run MOOSE `--check-input`;
4. run a one-electron-step Newton smoke test with the accepted timestep/tolerances;
5. only after that succeeds, run a multi-electron-step short discriminator and collect nonlinear iterations, linear work, elapsed time, positivity, charge and profiles;
6. compare at the same physical time against the qualified Gummel reference.

## Fail-closed rule

Do not repair Newton failure by changing physics, timestep, convergence tolerances, wall model, or by reintroducing a fixed-point/Gummel loop. Solver/preconditioner changes are allowed only after the first failure mode is captured and remain separately attributable.
